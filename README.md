# 🧬 UI DNA — The Visual DNA of Interfaces

> **“Every interface has a genetic signature.”**  
> *Analyze. Visualize. Mutate. Evolve.*

**UI DNA** is an experimental interface-analysis and UI-evolution platform. The application treats user interfaces as biological organisms, converting their visual characteristics into unique, deterministic interactive **DNA fingerprints**.

Developed by **Aditya Kumar Jha** (2026).

---

## ✨ Key Features

### 1. The 12 Genomic Traits
Every interface profile encodes 12 genetic dimensions ($0 - 100$), each featuring 3 granular sub-characteristics with block meters (`████████░░`):
* **Color Genome (`CLR`)**: Chromatic temperature, spectral saturation, and tonal variance.
* **Typography Genome (`TYP`)**: Optical hierarchy scale, weight contrast, and letter tracking.
* **Spacing Genome (`SPC`)**: Respiratory spatial rhythm, interstitial margins, and breathing room.
* **Radius Genome (`RAD`)**: Corner curvature, pill-morphing, and organic softness.
* **Shadow Genome (`SHD`)**: Z-axis elevation, ambient occlusion diffusion, and light spread.
* **Contrast Genome (`CTR`)**: Luminance delta, demarcation rigidity, and accessibility ratio.
* **Density Genome (`DNS`)**: Information packing efficiency and interactive target compacting.
* **Motion Genome (`MOT`)**: Spring physics damping, transition velocity, and kinetic resonance.
* **Layout Genome (`LAY`)**: Column grid multi-tracking, asymmetry factor, and alignment tension.
* **Component Genome (`CMP`)**: Atomic nesting depth, badge frequency, and state granularity.
* **Interaction Genome (`INT`)**: Tactile hover elasticity, aperture transitions, and ripple feedback.
* **Complexity Genome (`CPX`)**: Visual noise filtering, scanline texturing, and atmospheric depth.

### 2. Deterministic Visual DNA Generation
* **Mathematical Lattice**: Node positions, orbital radii, codon rungs, and outer loops are generated deterministically using an FNV-1a hash algorithm.
* **Unique DNA Identifiers**: Automatically generates unique specimen IDs (e.g. `UD-7F4A-91C2`).
* **Phenotypic Classifications**: Non-judgmental biological classifications (e.g. *"Minimal / Dynamic / Dense"*, *"Structured / Soft / Interactive"*).

### 3. Living 3D Animated Helix
* Interactive canvas double-helix with ambient particles and depth buffering.
* Reacts dynamically to cursor coordinates and rotational velocity.

### 4. Dedicated Analysis Lab
* **Mode 1 — Manual Analysis**: Fine-grained sliders, color pickers, and grouped controls.
* **Mode 2 — Screenshot Analysis**: Client-side HTML5 canvas pixel extraction for dominant colors, Shannon color entropy, RMS luminance contrast, and Sobel edge visual density. Labeled with scientific `[ESTIMATED]` tags.

### 5. Mutation Engine ("Mutation Lab")
* Generates 3 distinct evolutionary variations:
  - **Mutation A (Evolutionary Drift)**: Focused local drift preserving structural balance.
  - **Mutation B (Divergent Branch)**: Radical morphological inversion.
  - **Mutation C (Quantum Adaptation)**: Balanced multi-genome resonance shift.
* Adopting mutations triggers a particle burst and auto-commits to the Evolution History timeline.

### 6. Live UI Evolution Simulation
* Tangible interface organism that physically reacts to DNA traits:
  - **Radius** modulates corner curvature from $0\text{px}$ sharp brutalist to $28\text{px}$ organic pills.
  - **Motion** controls spring physics, hover scale multipliers, and transition durations.
  - **Spacing & Density** alter spatial margins and compact layouts.
  - **Contrast & Shadow** adjust surface depth, drop shadows, and border demarcation.

### 7. Comparative Divergence ("Compare DNA")
* Neutral side-by-side visual fingerprints for Specimen A and Specimen B.
* Trait comparison metric ladder (`Color 82 ───────── 65`).
* Genetic topology radar divergence chart.

### 8. Evolution History Timeline
* Horizontal timeline tracking generations ($V1 \rightarrow V2 \rightarrow V3\dots$).
* Instant time-travel and branch snapshotting.

### 9. Command Palette (`Ctrl + K` / `Cmd + K`)
* Fuzzy search and quick triggers for all laboratory workflows and presets.

### 10. Specimen Library & Export
* Pre-loaded with **Minimal Core**, **Neon Pulse**, **Editorial**, and **Organic** archetypes.
* Export as high-resolution visual **Share Card** or JSON payload (`RFC-7159`).
* Import existing DNA profiles from JSON.
* Local persistence via `localStorage`.
